# @doccue/protocol

The data the two halves of [DocCue](https://github.com/muyuzhong/DocCue) exchange: screen snapshots, recorded actions, guides, the conversation, requests and the event stream. Types, plus the protocol version. You need it directly only to build your own frontend or backend; `@doccue/core` and `@doccue/bridge` depend on it.
