# Allowed email domains

The list of email domains people can be invited from, on the **Members** page. A new workspace allows only the domain of the person who created it.

- Write domains without the @, separated by commas: `acme.test, partner.example`.
- Subdomains are separate: allowing `acme.test` does not allow `eu.acme.test`.
- Changes apply as soon as you press **Save domains**.
