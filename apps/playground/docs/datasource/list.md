# 数据源列表

「数据源」页面列出所有已接入的数据源：名称、类型、主机、端口和状态。

## 状态

- **正常**：最近一次连接成功。
- **连接失败**：最近一次连接失败。依赖它的报表和同步任务也会失败，仪表盘上「失败的同步」会因此增加。常见原因是数据库地址或端口变了、数据库停机，或者密码被修改。

## 编辑数据源

编辑功能还没有开放。需要修改连接信息时，先新建一个数据源，确认可用后再删除旧的。

## 删除数据源

在列表里点那一行的「删除」，在弹出的确认框里点「确定删除」。

- 删除后**无法恢复**。
- 依赖它的报表会失效，需要改用其他数据源。
- 删除不会影响数据库本身，只是平台不再连接它。
