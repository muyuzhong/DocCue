# 新建数据源

在「新建数据源」页面填写连接信息。必须先点「测试连接」并且连接成功，「保存」按钮才会变为可用。

## 名称

数据源在平台里的名字，用于在列表和报表中识别它，例如 orders-db。建议用业务含义命名，不要用 IP 地址。

## 数据库类型

从下拉框选择 MySQL、PostgreSQL 或 ClickHouse。切换类型后，记得把端口改成对应的值。

## 主机地址

数据库服务器的 IP 地址或域名，例如 10.0.0.8 或 db.internal。

- 不要带协议头：不能写 http:// 或 mysql://。
- 不要带端口：端口填在下面单独的「端口」里，不能写成 10.0.0.8:3306。

不符合这些要求时，会提示 Invalid Host Format。

## 端口

各数据库的默认端口：

| 数据库 | 默认端口 |
| :--- | :--- |
| MySQL | 3306 |
| PostgreSQL | 5432 |
| ClickHouse | 8123 |

如果你们的数据库改过端口，填实际的端口。端口只能是数字。

## 用户名和密码

连接数据库用的账号。建议使用只读账号：平台只读取数据，不会写入。密码保存后不会再显示。

## 使用 SSL

数据库要求加密连接时勾选。云厂商托管的数据库（如 RDS）通常要求 SSL；内网自建的数据库一般不需要。

## 测试连接

点「测试连接」后，平台会用填写的信息连接一次数据库：

- 成功时显示「连接成功」和数据库版本，「保存」变为可用。
- 失败时显示失败原因，常见原因见[连接问题排查](../troubleshooting.md)。

测试成功后再修改任何一项，「保存」会重新变为不可用，需要再测试一次。

## 保存

保存后回到数据源列表，新数据源的状态为「正常」。
