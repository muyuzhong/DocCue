# 连接问题排查

测试连接失败时，按提示的信息排查。

## Invalid Host Format

主机地址的格式不对。主机地址只能是 IP 或域名，不能带 http:// 等协议头，也不能带 :端口。例如应该填 127.0.0.1，而不是 http://127.0.0.1:5432。

## 请填写主机地址 / 请填写端口

对应的输入框是空的，填上后再测试。

## 端口只能是数字

端口里有字母、空格或其他字符。只填数字，例如 5432。

## 连接失败：connection refused

平台连到了这台主机，但对方拒绝了连接。最常见的原因：

1. 端口填错了，例如 PostgreSQL 填成了 5433。先确认数据库实际监听的端口，默认端口见[新建数据源](datasource/new.md)。
2. 数据库服务没有启动。
3. 防火墙没有放行平台的访问。

## 认证失败

用户名或密码不对，或者这个账号没有从平台所在网络登录的权限。请向数据库管理员确认账号。
