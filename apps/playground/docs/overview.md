# 数据平台简介

数据平台用来接入和管理数据库。把公司里的数据库登记成「数据源」后，报表和同步任务就可以从这些数据源读取数据。

## 页面

- **数据源**：查看已接入的数据源和它们的连接状态，删除不再使用的数据源。
- **新建数据源**：填写连接信息，测试连接，保存一个新的数据源。
- **仪表盘**：查看数据源数量、今日查询次数和失败的同步任务。
- **设置**：修改接收告警的通知邮箱。

左侧菜单可以在这几个页面之间切换。

## 支持的数据库

目前支持 MySQL、PostgreSQL 和 ClickHouse。其他数据库（如 Oracle、SQL Server）暂不支持。
